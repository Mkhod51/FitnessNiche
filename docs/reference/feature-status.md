## Reading the matrix

`implemented` means a user-visible path exists in current source. It does not imply every deployment or hardware boundary has an end-to-end test. `implemented but not user-wired` means working code is not reachable through the product UI. `partial` identifies a shipped slice with a material requirement, behaviour, or verification gap. `planned` has no complete runtime path. `out of scope` is an explicit product boundary.

The source audits behind this matrix are preserved in the dated documentation-overhaul workspace. Current code and tests take precedence over those snapshots if they diverge.
