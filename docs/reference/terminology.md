# Terminology

**Status:** current seed glossary; terminology expansion is owned by documentation Tasks 4 and 6.

- **Claim** — a curated, graded statement with one or more citations and a stable identifier.
- **Evidence grade** — A–D confidence classification defined by the evidence rubric.
- **Surface** — a product context in which a claim may be shown.
- **Snapshot** — deterministic user-state input evaluated against claim predicates.
- **Local-first** — the on-device database is the primary write path; network sync is optional.
- **Tombstone** — a soft-delete marker that can replicate through sync.

For normative field meanings see the [claim schema](../../app/claims/schema.md); for implementation status see [feature status](feature-status.md).
