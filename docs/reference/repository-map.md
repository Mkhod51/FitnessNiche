# Repository map

**Status:** current scope page; the source-of-truth and change-trigger map is owned by documentation Task 5.

- `app/src/` — PWA runtime, domain logic, local data, features, and sync client.
- `app/claims/` — authored claim YAML and curation contracts.
- `app/server/` — optional Cloudflare Worker/D1 sync service.
- `app/e2e/` — Playwright browser coverage.
- `docs/` — current documentation plus retained research and history.

The expanded map will link representative files and explain when each area changes, rather than reproducing a large directory tree. Start with the [system overview](../architecture/system-overview.md) and [development guide](../guides/development.md).
