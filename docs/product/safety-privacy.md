# Safety and privacy

**Status:** current scope page; detailed guardrail and privacy coverage is owned by documentation Task 4.

MyoStat keeps health data on the device by default, requires consent before logging, and provides export and device erasure. Nutrition targets pass through code-level calorie floors and deficit caps; advice uses wellness framing and stored claim provenance. It does not diagnose disease or use an LLM in the runtime advice path.

See the [normative requirements](../REQUIREMENTS.md) for GR/NFR obligations and [feature status](../reference/feature-status.md) for known implementation limits, including server-side erasure.
