# Screenshot assets

**Status:** current ownership contract; no product screenshots have been created yet. Reproducible capture tooling and images are owned by documentation Task 8.

Future screenshots must use deterministic synthetic data, a fixed documented viewport, stable filenames, the app's default theme, and no personal or existing health data. Every image needs meaningful alt text and a caption that explains what to inspect. Text and source remain authoritative when a capture becomes stale.

The final inventory will record each image's seed state and exact capture command. Until that tooling exists, do not add hand-captured product images or use screenshots as evidence that a workflow is complete.
