# Advice engine

**Status:** current scope page; the complete source-traced trust path is owned by documentation Task 6.

Runtime advice is selected deterministically from a validated, build-time claim bundle. A rendered recommendation carries a stored claim identifier; claim content and citations are not invented by a model at runtime.

This page will own the four selection routes, suppression and cooldown rules, contested-claim handling, and provenance flow. See [JSON Logic](json-logic.md), [evidence curation](../guides/evidence-curation.md), and the normative [claim schema](../../app/claims/schema.md).
